Parcial 2 / Proyecto final
SPA para calcular costos de productos para emprendedores pasteleros. 
Primero se cargan los ingredientes, luego en la parte de productos se pueden agregar los ingredientes. Al agregar el margen de ganancia, el campo de precio se rellena automáticamente.
Para levantarlo hay que correr el comando "npm run dev" en back y front.
